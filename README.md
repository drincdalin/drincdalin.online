# drincdalin.online

hi everybody! welcome to the repo for my personal website. 
i basically built this because i needed a clean place to showcase my projects for some national and county-level competitions, and also just to learn more web dev stuff.

**live site:** [drincdalin.online](https://drincdalin.online) (hopefully it doesn't crash)

## tech stack
i tried to keep the code pretty simple (mostly because i'm still learning and CSS is hard), but here is what's running it:
*   **HTML5 & CSS3** - written from scratch. no tailwind or bootstrap because i wanted to suffer and actually learn how custom properties (`:root`) work.
*   **Vanilla JS** - just a tiny bit for links and stuff.
*   **Media Queries** - managed to make it responsive so it doesn't look totally broken on mobile (tested on my phone, looked okay-ish).

## file structure
*   `index.html` -> the main page (has my bio, skills, and a sneak peek of projects)
*   `projects.html` -> the page with the full list of things i've actually built or worked on
*   `style.css` -> a very long stylesheet. i used a `?v=2` cache buster because my browser refused to update the styling changes i kept making 😭
